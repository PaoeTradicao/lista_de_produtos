Configuração inicial

Cole abaixo a configuração do seu projeto Firebase (o objeto firebaseConfig que aparece no console do Firebase, em Configurações do projeto → Seus apps). Isso só precisa ser feito uma vez neste aparelho.

Onde encontro isso?

No console do Firebase (console.firebase.google.com), crie um projeto novo e exclusivo para este site. Depois vá em Configurações do projeto → aba Geral → seção "Seus apps" → crie um app da Web e copie o objeto de configuração exibido. Em seguida, no Firestore Database, crie o banco de dados (modo produção) e ajuste as regras de acesso antes de usar o site com dados reais.
